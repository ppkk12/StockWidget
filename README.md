# 株価ウェジット

<img width="1535" height="980" alt="image" src="https://github.com/user-attachments/assets/3dc7569b-5b58-40ed-948c-eac748e58866" />

## 概要📝

デスクトップに常駐させる株価チャートのウィジェット

・日本株（7203 のように入力すると自動で .T を付けます）と米国株（AAPL など）に対応

・現在値・騰落率・チャート・出来高、始値や PER など9項目の指標を表示

・期間は1日〜1年間の7種類、更新間隔は3秒〜1日の5段階から選択

・ウィジェットは複製して何個でも並べられ、位置や設定は次回起動時に復元

・透過率（0〜100%）、すりガラス、最前面固定、トレイ常駐、OSログイン時の自動起動

## ダウンロード方法⇩↓

### https://github.com/ppkk12/StockWidget/releases/tag/v1.0.0

StockWidget Setup 1.0.0.exe を実行してインストールします。インストール後は、デスクトップのショートカットから起動します。

## 対応OS・バージョン💻

アプリ: v1.0.0

Windows 10 / 11（64bit）

すりガラス機能は Windows 11 だけで使えます

## 注意事項📋

・インターネット接続が必要です

・株価は Yahoo Finance の非公式APIから取得しています。日本株は最大20分ほど遅れることがあり、仕様変更で取得できなくなる可能性もあります

・3秒毎の更新を多くのウィジェットで同時に使うと、取得制限にかかることがあります

・コード署名をしていないため、初回インストール時に SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で進めることができます
